# The ONLY deliberate change to the SHELL_CPU=mb block design since the fielded
# baseline (eafe787, the 2026-10 ILA mint's shell_bd.tcl): D13 -- usd_spi_0
# (USD, the user-microSD SPI master) replaces the pad-less axi_quad_spi_0
# (OVLSTORE) on 0x44A4_0000 and on interconnect port M03.
#
# Format: tests/shell_cpu_seam/seam_dump.py `delta <baseline> <seam_mb>` -- every
# dump line with its ancestry (`CELL /x > PIN y > CONFIG.k=v`), NET/INET exploded
# per member, `-` = only in the baseline, `+` = only in this tree, sorted.
# Dumps: Vivado 2024.1, SHELL_CPU=mb SHELL_TOUCH=1 SHELL_REALPHY=0,
# fpga/shell/tools/shell_bd_dump_run.tcl. Checked by run_seam_gate.sh step 2
# (`compare --expect-delta`, exact); every line is held to the cell swap by
# test_shell_cpu_seam.py (test_d13_delta_is_only_the_usd_cell_swap).
#
# What it says, in words:
#   - axi_quad_spi_0: the whole cell -- VLNV, every CONFIG, every pin, its
#     AXI_LITE/SPI_0 interfaces, its three clock/reset net memberships
#     (ext_spi_clk, s_axi_aclk, s_axi_aresetn), its M03 intf net end and its
#     0x44A40000/64K segment -- is gone.
#   + usd_spi_0 (soclabs.org:user:usd_spi:1.0, C_S_AXI_ADDR_WIDTH=32,
#     DEBOUNCE_CYCLES=1000000 default): the cell, its s_axi on M03, s_axi_aclk /
#     s_axi_aresetn on the same shell_clk / peripheral_aresetn nets, the same
#     0x44A40000/64K segment, and eight new scalar BD ports + nets (usd_clk_o/oe,
#     usd_cmd_o/oe, usd_dat0_i, usd_dat3_o/oe, usd_ncd_i).
#   ~ M03 only, propagated from the new slave's interface: usd_spi's s_axi has
#     HAS_PROT=1, so the M03 arprot/awprot pins of axi_interconnect_0 and
#     m03_couplers become [2:0] vectors (were unsized/unconnected); and it
#     declares NUM_READ/WRITE_OUTSTANDING=1, so tier2_xbar_0's M03_AXI follows
#     (2 -> 1). No other master port, cell, CONFIG, net name or address moved.
